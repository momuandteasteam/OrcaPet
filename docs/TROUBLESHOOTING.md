# トラブルシューティング

## Petが表示されない

- 「Petをインストール…」から再度選択します。
- `pet.json`の`spriteVersionNumber`が`2`であることを確認します。
- `spritesheetPath`が実在するファイルを指していることを確認します。

## 設定画面を閉じられない

右上の×または`Esc`キーで閉じます。設定パネルの外側をクリックしても閉じられます。

## Orcaの状態が更新されない

```sh
/Applications/Orca.app/Contents/Resources/bin/orca worktree ps --json
```

このコマンドがJSONを返すか確認します。プロジェクト専用Petでは、選んだフォルダとOrca Worktreeのパスが一致している必要があります。

## Petが勝手に走る

アイドル状態が12秒続くと、近い画面端まで一度だけ走ります。クリックで停止できます。不要なら「アイドル時に端へ走る」をオフにします。

## アプリを開けない

配布版が署名・公証済みか確認してください。未署名の開発ビルドでは、FinderからControlキーを押しながらクリックして「開く」を選択できます。
