# プライバシーとセキュリティ

OrcaPetはローカルで動作します。独自の分析送信、アカウント登録、クラウド同期はありません。

## 読み取る情報

- Orca CLIの`worktree ps --json`出力
- プロジェクト名、ブランチ、エージェント種類と状態
- 稼働・完了・待機・未読・ターミナル数
- `~/.codex/pets/`と`~/.orcapet/pets/`内のPetマニフェストと画像

プロンプト本文、エージェントの回答本文、APIキー、ソースコード内容は表示・送信しません。Orca CLIを利用できない場合は、ローカルのプロセス一覧から対応エージェントの稼働だけを判定します。

## Petインストーラー

ZIPの絶対パス、`..`を使うパストラバーサル、過剰なファイル数を拒否します。インストール対象としてコピーするのは検証済みの`pet.json`とスプライトシートだけです。
